# Случайное слово

Консольная программа принимает целое число от 0 до 100 и выводит одно русское слово из онлайн-словаря.

## Запуск

Нужны Python 3.12 и подключение к интернету.

```bash
python main.py
```

## Как выбирается слово

1. Введённое число умножается на случайное целое число от 1 до 5.
2. К факториалу произведения прибавляется случайное целое число от 0 до 100.
3. Программа вычисляет SHA-256 от десятичной записи результата. Хеш преобразуется в целое число. Остаток от деления на 56 624 даёт номер строки словаря.
4. Программа отправляет этот номер в параметре `offset` и запрашивает одну строку с помощью `length=1`. Из ответа она берёт поле `russian_word`.

Например, при вводе `45`, множителе `2` и добавке `22` программа хеширует десятичную запись `90! + 22`. Получается номер строки `34497`. В ней словарь возвращает «представление».

При повторном вводе того же числа множитель и добавка выбираются заново. Слово может совпасть, если расчёты привели к той же строке или если слово встречается в словаре несколько раз.
