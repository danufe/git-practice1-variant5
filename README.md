# Случайное слово

Консольное приложение для практической работы № 2 по CI/CD.
Пользователь вводит целое число от 0 до 100. Программа выполняет вычисления
и выводит одно случайное слово из встроенного списка.

## Алгоритм

1. Введённое число умножается на случайное целое число от 1 до 5.
2. Вычисляется факториал произведения.
3. К факториалу прибавляется случайное целое число от 0 до 100.
4. От десятичной записи суммы вычисляется SHA-256.
5. Хеш преобразуется в целое число. Остаток от деления на количество слов
   задаёт индекс слова в списке.

Например, ввод 45 и множитель 3 дают 135! + случайная добавка, затем хеш определяет слово.
Повторные запуски могут возвращать одинаковые слова.

## Запуск

Требуется Python 3.12. Используется стандартная библиотека Python.

```bash
python main.py
```

Введите число, например 45. Результатом будет одно слово, например `ветер`.
Число входит в вычисление факториала и влияет на хеш, по которому выбирается слово.
При успешном запуске код завершения равен 0. При ошибке ввода — 1.

## Тестирование

```bash
python -m unittest discover -s tests -v
```

Восемь модульных и интеграционных тестов проверяют границы диапазона,
вычисления и консольный запуск.

## Документация

```bash
python -m scripts.build_docs
```

HTML сохраняется в build/docs/index.html. Он содержит версию, ревизию кода,
список слов и описания функций из исходного кода.

## CI/CD

Файл .github/workflows/main.yml запускает тесты и сборку документации
при push в любую ветвь и при создании или обновлении PR в main.
HTML доступен в разделе Artifacts под именем project-docs.

После успешных тестов PR из development и release автоматически сливаются
в main. Затем запускается контрольная проверка основной ветви.

Версия хранится в config.py. Для публикации тега в Actions запустите
Python CI/CD на main с параметром publish_tag.
