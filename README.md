
# Случайное слово

## 1. Описание проекта

Консольное приложение для получения случайного русского
слова из онлайн-словаря на основании введённого числа.

Текущая версия: 1.0.1.

## 2. Системные требования

- Python 3.12.
- Подключение к интернету.
- Windows, Linux или macOS.
- Установка дополнительных библиотек не требуется.

## 3. Запуск приложения

Обычный запуск:

```bash
python main.py
```

Вывод слова в верхнем регистре:

```bash
python main.py --uppercase
```

Просмотр текущей версии:

```bash
python main.py --version
```

## 4. Алгоритм работы

1. Пользователь вводит целое число от 0 до 100.
2. Число умножается на случайное число от 1 до 5.
3. Вычисляется факториал полученного произведения.
4. Прибавляется случайное число от 0 до 100.
5. Результат хешируется алгоритмом SHA-256.
6. Хеш преобразуется в целое число.
7. Вычисляется остаток от деления на 56624.
8. Полученный индекс отправляется в API словаря.
9. Из ответа API извлекается русское слово.
10. Результат выводится пользователю.

## 5. Основные функции

| Функция | Назначение |
| --- | --- |
| word_index() | Вычисление индекса слова |
| fetch_word() | Получение слова через API |
| format_word() | Форматирование результата |
| main() | Управление работой приложения |

## 6. Используемые технологии

- Python — язык программирования.
- random — генерация случайных чисел.
- math — вычисление факториала.
- hashlib — хеширование SHA-256.
- urllib — выполнение HTTP-запросов.
- json — обработка ответа API.
- unittest — автоматическое тестирование.
- GitHub Actions — непрерывная интеграция.

## 7. Автоматическое тестирование

В проекте реализовано 27 модульных тестов.

Для запуска тестирования используется команда:

```bash
python -m unittest discover -v
```

Проверяются:

- вычислительный алгоритм;
- граничные значения;
- некорректные входные данные;
- обработка ответов API;
- обработка сетевых ошибок;
- форматирование слов;
- отображение версии приложения.

## 8. CI/CD

GitHub Actions обеспечивает:

- автоматическую проверку синтаксиса;
- автоматическое выполнение модульных тестов;
- проверку изменений при push;
- проверку Pull Request.

Автоматическое слияние Pull Request выполняется
средствами GitHub после прохождения обязательных проверок.
