# Погодное слово

Простое консольное приложение для практической работы № 2 по CI/CD.
Число выбирает город. Приложение получает текущий код погоды через
[Open-Meteo](https://open-meteo.com/), затем случайно выбирает одно слово,
соответствующее типу погоды.

## Запуск

Запустите программу с Python 3.12 из корня репозитория.

```bash
python main.py
```

Введите `1` для Москвы, `2` для Санкт-Петербурга или `3` для Казани.
При дожде программа может вывести `капля`. Для получения погоды нужен интернет.
При неверном вводе программа завершается с кодом 2, при ошибке получения
погоды — с кодом 1.

## Тесты и документация

```bash
python -m unittest discover -s tests -v
python -m scripts.build_docs
```

20 тестов проверяют ввод, выбор слова, обработку ответа API и консольный
запуск. Проверки используют подмену API и локальный HTTP-сервер.
Документация сохраняется в `build/docs/index.html`.

## GitHub Actions

Workflow `Python CI/CD` выполняет тесты и собирает HTML при push в любую
ветвь и в pull request в `main`. Архив HTML доступен в **Artifacts** под
именем `project-docs`. Готовые pull request из `development` и `release`
этого репозитория автоматически вливаются после проверки.

Чтобы опубликовать тег для версии в `config.py`, откройте **Actions → Python
CI/CD → Run workflow**, выберите `main` и отметьте `publish_tag`. Задание
публикует тег на проверенном коммите.
