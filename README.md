# Случайное слово

Консольное приложение для практической работы № 2 по CI/CD.
Пользователь вводит целое число от 0 до 100. Программа выполняет вычисления
и выводит одно случайное слово из встроенного списка.

## Алгоритм

1. Функция `main()` читает строку из консоли и преобразует её в целое число `n` через `int()`. Функция `choose_word(n)` проверяет, что число входит в диапазон от 0 до 100 включительно.
2. Первый вызов `random.randint(1, 5)` выбирает множитель `k`. Произведение `n × k` лежит между 0 и 500.
3. `math.factorial()` вычисляет факториал произведения. Например, `4! = 1 × 2 × 3 × 4 = 24`. Для нуля по определению `0! = 1`.
4. Второй вызов `random.randint(0, 100)` выбирает добавку `a`. Итоговое число равно `(n × k)! + a`.
5. Программа превращает итоговое число в десятичную строку, кодирует её в UTF-8 и вычисляет SHA-256. Метод `.digest()` возвращает 32 байта хеша.
6. `int.from_bytes(digest, "big")` читает эти байты как одно целое число, начиная со старшего байта. Остаток от деления на `len(WORDS)` даёт индекс от 0 до 15. По этому индексу функция возвращает одно из 16 слов.

### Пример для числа 45

Пусть множитель равен 3, а добавка равна 72. Произведение равно `45 × 3 = 135`. Программа хеширует десятичную запись суммы `135! + 72`. Хеш в шестнадцатеричном виде оканчивается на `6`. Поскольку в списке 16 слов, последняя шестнадцатеричная цифра равна остатку от деления на 16. Получаем индекс 6 и слово **«облако»**.

При фиксированных множителе и добавке расчёт воспроизводим. В обычном запуске эти два числа выбираются заново. Разные расчёты могут привести к одному индексу и одному слову.

## Запуск

Для запуска достаточно Python 3.12 и его стандартной библиотеки.

```bash
python main.py
```

Введите целое число, например `45`, и нажмите Enter. Подсказка выводится в
`stderr`, а в `stdout` приходит одна строка со словом. При успешном запуске
программа возвращает код 0. Текст, дробь, число за пределами диапазона и
отсутствие ввода приводят к сообщению об ошибке и коду 1.

## Тестирование

Выполни команду из корня репозитория.

```bash
python -m unittest discover -s tests -v
```

`unittest` находит и выполняет 20 тестов, а `-v` выводит имя и результат каждого. [Файл tests/test_main.py](tests/test_main.py)

### Модульные тесты

Класс `WordTests` проверяет расчёт напрямую через `choose_word()`. В блоке
`with patch("main.random.randint", side_effect=[3, 72])` первый вызов
`randint()` возвращает 3, а второй — 72. Это позволяет заранее вычислить ожидаемое слово и
сверять один и тот же ответ при каждом запуске теста.

| Проверка | Ожидаемый результат |
|---|---|
| Нижняя граница 0, множитель 5 и добавка 0 | Для `0! = 1` получается «луна». |
| Верхняя граница 100, множитель 5 и добавка 100 | Для `500! + 100` получается «море». |
| Число −1 | `ValueError` с указанием допустимого диапазона. |
| Число 101 | `ValueError` с указанием допустимого диапазона. |
| Ввод 45 и множитель 3 | Факториал получает аргумент 135. |
| Два вызова генератора | Первый запрашивает диапазон 1–5, второй 0–100. |
| Ввод 4, множитель 2 и добавка 9 | В SHA-256 передаётся `b"40329"`, так как `8! + 9 = 40329`. |
| Хеш, который как целое число равен 33 | Остаток `33 % 16 = 1` даёт слово «река». |
| Полный расчёт для 45, множителя 3 и добавки 72 | Программа возвращает «облако». |
| Ввод 2 и ввод 3 при множителе 1 и добавке 0 | Для 2 получается «лес», для 3 — «солнце». |

### Консольные тесты

Класс `ConsoleTests` запускает `main.py` в отдельном процессе и передаёт
строку через `stdin`. Для допустимого ввода он сверяет код 0, ровно одну
строку со словом из `WORDS` в `stdout` и подсказку в `stderr`. Для
ошибочного ввода он сверяет код 1, пустой `stdout` и сообщение об
ошибке после подсказки в `stderr`.

| Ввод | Что проверяется |
|---|---|
| `45` | Обычный запуск с корректным числом. |
| `" 45 "` | Пробелы вокруг числа допускаются. |
| `0` | Нижняя граница принимается из консоли. |
| `100` | Верхняя граница принимается из консоли. |
| `-1` | Число ниже диапазона отклоняется. |
| `101` | Число выше диапазона отклоняется. |
| `abc` | Строка с буквами отклоняется. |
| `3.5` | Дробное число отклоняется. |
| Пустая строка | Нажатие Enter без числа обрабатывается как ошибка. |
| Конец ввода | Завершение потока до первой строки обрабатывается как ошибка. |
