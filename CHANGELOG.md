# Изменения

## 0.4.0

- Добавлен генератор слов по числу от 0 до 100, случайному множителю, факториалу и SHA-256.
- Добавлены восемь модульных и интеграционных тестов.
- HTML документация учитывает актуальный список слов и версию.
